# خط إدخال الكتب المدرسية

كل خطوة برنامج مستقل. ملفات الكتب تبقى في مجلد الكتب على اللابتوب، ولا تُرفع أبدًا.

| الخطوة | البرنامج | الحالة |
|---|---|---|
| ١. التسجيل: البصمة والصفحات ونوع النص | register.py | جاهز |
| ٢. استخراج نص كل صفحة | extract.py | جاهز |
| ٣. القراءة الضوئية للصفحات الممسوحة | ocr.py | بعد معرفة نوع الكتب الفعلية |
| ٤. التقسيم لوحدات ودروس | segment.py | بعد رؤية فهرس أول كتاب حقيقي |
| ٥. مسودة الدروس | داخل جلسات العمل مع المساعد | لاحقًا |
| ٦. التحقق الآلي | فاحص المحتوى العام | جاهز |
| ٧. صفحة المراجعة | review.py | لاحقًا |

## التشغيل

ضع ملف الكتاب في المسار المكتوب له في سجل المصادر، ثم:

```
ingest/.venv/Scripts/python.exe ingest/register.py --all
ingest/.venv/Scripts/python.exe ingest/extract.py smile.g1.pupil
npm run validate
```

## إضافة كتاب جديد

أضف سطرًا في سجل المصادر بمعرّف وصف ومادة ومستوى ثقة، وضع الملف في مجلد الكتب، ثم شغّل التسجيل.
