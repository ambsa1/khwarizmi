# خوارزمي

لعبة مجانية لتعليم الأطفال البرمجة بلغة بايثون، وعالم الكمبيوتر، والإنجليزية، والرياضيات، من عمر ٣ إلى ٩ سنين، مع الروبوت سِراج.
تشتغل على أي جهاز فيه متصفح حديث، وتتثبّت على الشاشة الرئيسية، وتشتغل بدون إنترنت بعد أول فتح.

## رابط اللعبة

```
https://ambsa1.github.io/omran/
```

الرابط ده بيحوّل تلقائيًا للعبة الجديدة في مجلد النسخة الثانية. كل أسرة تفتحه يكون ليها تقدّمها الخاص على جهازها.

## محتوى اللعبة

| القسم | ما فيه |
|---|---|
| عالم البرمجة | سبعين مرحلة في ثمانية مسارات، والكود الحقيقي بلغة بايثون ظاهر تحت البطاقات |
| مختبر بايثون | الطفل الكبير يكتب كود بايثون حقيقي بنفسه |
| عالم الكمبيوتر | ما هو الكمبيوتر، وأجزاؤه، والأيادي الصغيرة، ومدرسة الكتابة، والأمان على الإنترنت، وكيف يفكّر الكمبيوتر |
| الإنجليزية | الألوان والأرقام والحيوانات والجسم والعائلة والطعام والبيت وجمل قصيرة، بصوت إنجليزي والترجمة مكتوبة تحته |
| الرياضيات | العدّ والأشكال، الجمع والطرح، الضرب، القياس والساعة، الكسور والنقود، وتحدّي السرعة |
| موسوعتي | كل كلمة وفكرة تعلّمها الطفل، بالشرح والصوت |
| الجوائز | النجوم، والألقاب، والملصقات، والشهادات |
| ركن الأهل | الوقت، وحدّ اللعب اليومي، والنسخ الاحتياطي، ونقل التقدّم بين الأجهزة |

## التجربة على اللابتوب

من داخل مجلد المشروع:

```
python -m http.server 8765
```

وبعدها افتح:

```
http://localhost:8765/v2/
```

## أين توجد الملفات

كل ملفات اللعبة داخل مجلد النسخة الثانية:

| المجلد أو الملف | محتواه |
|---|---|
| `v2/js/levels.js` | المراحل كلها |
| `v2/js/texts.js` | كلام سراج العام وأسماء البطاقات |
| `v2/js/cw/` | قسم عالم الكمبيوتر |
| `v2/voice/` | ملفات صوت سراج |
| `v2/tests/` | الاختبارات التلقائية |
| `v2/docs/` | ملفات العمل الداخلية (بالإنجليزي، للمساعدين والمراجعين) |
| `v2/CREDITS.md` | المكتبات والخطوط والأصوات المستخدمة وتراخيصها |

## بعد أي تعديل

١. لو تغيّر أي كلام، ولّد الصوت (يحتاج إنترنت):

```
node v2/tools/voice.js
```

```
python v2/tools/make_voice.py
```

٢. حدّث قائمة الملفات المحفوظة للعمل بدون إنترنت:

```
node v2/tools/precache.js
```

٣. شغّل الاختبارات من داخل مجلد الاختبارات:

```
node run.js
```

ملاحظة مهمة: لا تغيّر رقم أي مرحلة موجودة، لأن تقدّم الأطفال محفوظ به.

## الخصوصية

بيانات الأسرة (الأسماء) مشفّرة داخل اللعبة، ولا تظهر إلا بكود الأسرة من ركن الأهل.
الأسماء والكود محفوظين فقط في ملفات محلية على اللابتوب، وهي غير مرفوعة على الإنترنت.
