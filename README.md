# خوارزمي

لعبة مجانية لتعليم الأطفال من عمر ٣ إلى ٩ سنين، مع الروبوت سِراج: البرمجة بلغة بايثون، وعالم الكمبيوتر، والإنجليزية، والرياضيات.
تشتغل على أي جهاز فيه متصفح حديث، وتتثبّت على الشاشة الرئيسية، وتشتغل بدون إنترنت بعد أول فتح.

## رابط اللعبة

```
https://ambsa1.github.io/khwarizmi/
```

كل أسرة تفتح الرابط يكون ليها تقدّمها الخاص على جهازها.

## محتوى اللعبة

| القسم | ما فيه |
|---|---|
| البرمجة | خمسة وسبعين مرحلة في ثمانية مسارات، والكود الحقيقي بلغة بايثون ظاهر تحت البطاقات، ومختبر بايثون للكبار |
| عالم الكمبيوتر | ما هو الكمبيوتر، وأجزاؤه، والأيادي الصغيرة، ومدرسة الكتابة، والأمان على الإنترنت، وكيف يفكّر الكمبيوتر |
| الإنجليزية | الألوان والأرقام والحيوانات والجسم والأسرة والأكل والبيت وجمل قصيرة، بصوت إنجليزي والترجمة مكتوبة |
| الرياضيات | العدّ، والأشكال، والجمع والطرح، والضرب، والقياس والساعة، والكسور والنقود، وتحدّي السرعة |
| موسوعتي | كل كلمة وفكرة تعلّمها الطفل، بالشرح والصوت |
| الجوائز | النجوم، والألقاب، والملصقات، والشهادات |
| ركن الأهل | الوقت، وحدّ اللعب اليومي، والنسخ الاحتياطي، ونقل التقدّم بين الأجهزة |

## التجربة على اللابتوب

من داخل مجلد المشروع:

```
python -m http.server 8765
```

وبعدها افتح:

```
http://localhost:8765/
```

## أين توجد الملفات

| المجلد أو الملف | محتواه |
|---|---|
| `js/levels.js` | مراحل البرمجة كلها |
| `js/texts.js` | كلام سراج العام وأسماء البطاقات |
| `js/cw/` | قسم عالم الكمبيوتر |
| `js/en/` | قسم الإنجليزية |
| `js/math/` | قسم الرياضيات |
| `voice/` | ملفات الصوت |
| `tests/` | الاختبارات التلقائية |
| `docs/` | ملفات العمل الداخلية (بالإنجليزي، للمساعدين والمراجعين) |
| `CREDITS.md` | المكتبات والخطوط والأصوات المستخدمة وتراخيصها |

## بعد أي تعديل

١. لو تغيّر أي كلام، ولّد الصوت (يحتاج إنترنت):

```
node tools/voice.js
```

```
python tools/make_voice.py
```

٢. حدّث قائمة الملفات المحفوظة للعمل بدون إنترنت:

```
node tools/precache.js
```

٣. شغّل الاختبارات من المجلد الرئيسي، مثلًا:

```
node tests/run.js
```

ملاحظة مهمة: لا تغيّر رقم أي مرحلة أو نشاط موجود، لأن تقدّم الأطفال محفوظ به.

## الخصوصية

بيانات الأسرة (الأسماء) مشفّرة داخل اللعبة، ولا تظهر إلا بكود الأسرة من ركن الأهل.
الأسماء والكود محفوظين فقط في ملفات محلية على اللابتوب، وهي غير مرفوعة على الإنترنت.
