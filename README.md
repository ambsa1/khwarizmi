# عمران

لعبة لتعلّم البرمجة بلغة بايثون للأطفال من ٤ إلى ٩ سنين، مع الروبوت منيب. تعمل بدون إنترنت على أي جهاز فيه متصفح حديث.

## التجربة على اللابتوب

```
python -m http.server 8765
```

وبعدها افتح في المتصفح:

```
http://localhost:8765
```

## ملفات اللعبة

| الملف | محتواه |
|---|---|
| `js/levels.js` | الأقسام والمراحل وكلام منيب في كل مرحلة |
| `js/texts.js` | الجمل العامة، أسماء البطاقات، القاموس، الألقاب |
| `js/engine.js` | محرك تنفيذ البرنامج |
| `js/app.js` | الشاشات والواجهة |
| `voice/` | ملفات صوت منيب |
| `sw.js` | تشغيل اللعبة بدون إنترنت |

## بعد أي تعديل

1. تأكد إن كل المراحل سليمة:
   ```
   node tools/validate.js
   ```
2. لو غيّرت أي كلام، ولّد الصوت الجديد (يحتاج إنترنت):
   ```
   node tools/collect_texts.js
   python tools/make_voice.py
   ```
3. غيّر رقم النسخة في أول سطر من `sw.js` (مثلاً من `omran-v1` إلى `omran-v2`) عشان الأجهزة تنزّل التحديث.

ملاحظة مهمة: لا تغيّر `id` أي مرحلة موجودة، لأن تقدّم الأطفال محفوظ به.

## رابط اللعبة

```
https://ambsa1.github.io/omran/
```

## نشر تحديث للأجهزة

بعد تعديل اللعبة وتجربتها، والتأكد من تغيير رقم النسخة في `sw.js`:

```
git add -A
git commit -m "وصف التحديث"
git push
```

خلال دقيقة أو دقيقتين يتحدّث الرابط، وكل جهاز ياخد النسخة الجديدة أول ما يفتح اللعبة وفيه إنترنت.
